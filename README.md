# Sistema de Registro de Sumário

Este é um projeto desenvolvido para registrar e gerenciar sumários. Ele foi criado como parte de um exercício anterior, usando PHP, e não será mais mantido ou atualizado. O foco principal foi a funcionalidade do sistema.

## Funcionalidades
- Registro de sumários
- Armazenamento de informações de estudantes e suas aulas
- Interface simples com funcionalidades básicas

## Como Rodar
1. Instale o servidor local (exemplo: WAMP, XAMPP).
2. Coloque a pasta `Sistema de Registro de Sumário` dentro da pasta `www` (ou equivalente) no diretório de instalação do seu servidor.
3. Abra o navegador e acesse `http://localhost/Sistema de Registro de Sumário`.

## Tecnologias Usadas
- PHP
- MySQL (Banco de Dados)

## Aviso
Este projeto não possui o melhor design, mas está funcional. Não será mantido, pois o foco foi na parte lógica de desenvolvimento.
